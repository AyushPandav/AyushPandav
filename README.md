### 🧭 About Me

I build **practical software** — from interfaces and APIs to databases, deployment pipelines, and AI-powered features. Currently pursuing a **B.E. in Information Technology**, I work across the full stack and enjoy figuring out how the pieces fit together well enough to ship a complete product, not just a prototype.

I don't build projects just to pad a portfolio. **I build things that solve a real problem, teach me something new, or can go beyond the prototype stage.**

```text
Learn → Build → Break → Debug → Improve → Ship
```

- 🔭 Currently building **AI & data-driven applications**
- 🌱 Currently learning **cloud deployment, Docker & CI/CD pipelines**
- 🧑‍💻 Technical Lead — **DevOps Club**, my college
- 🏆 1st Place — **HackStreak 2.0**
